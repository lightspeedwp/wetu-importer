# Wetu Content Importer — Developer Guide

This folder documents the internal classes and functions of the **Wetu Content Importer** plugin (`lsx-importer-for-wetu.php`, plugin slug `lsx-wetu-importer`). It is aimed at developers maintaining or extending the plugin, not at end users (see the root `README.md` / `readme.txt` for user-facing docs).

The plugin imports content from the [Wetu](https://wetu.com/) tour-operator API into the [Tour Operator](https://touroperator.solutions/) plugin's custom post types (`tour`, `accommodation`, `destination`).

## How this guide was produced

Generated by reading every `.php` file under `classes/`, `bin/`, and `includes/` in full and documenting every class, property, and method: signature, purpose, WordPress hooks fired/registered, and side effects (DB writes, API calls, file I/O). Where the code's actual behavior diverged from what its name/docblock implied, that's flagged in [Known Issues](known-issues.md) rather than glossed over.
